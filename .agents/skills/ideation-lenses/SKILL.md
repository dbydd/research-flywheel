# 选题与攻击面透镜

同一套问题表，四处用：planner 拿它定档派题，pi 拿它自证（只自证，永不自判），speculator 拿它生成假设，examiner 拿它开火。检查表静默跑——通过项不落文字；失败以一条锚到「段+句+证据」的 finding 落进 `research_project/<项目短名>/对线记录.md` 或 `gates/`。不为填表而填表；一条能覆盖多个相邻步骤的记录就够。

## ① 选题三 gate（planner 派题单）

| gate | 问题 | 判据 |
|---|---|---|
| 重要 | 谁在为此受苦、受多深的苦 | 答案只有「研究这个窄问题的别的研究者」= 不放行（F4）；须点名一个外部受益者与一条可测后果 |
| 可行 | 本飞轮现有资源能否在生命周期内跑完一轮完整链条 | 数据可及且不触禁区三条；评测器已存在或可先建；`objectives` 四要素（metric/evaluator/direction/epsilon + baseline）填得出；单片 ≤45 min 串得完（F5/F7） |
| 时机 | 为什么是现在 | 需要还不存在的能力 → park；五年前就能做 → 先派 librarian 查文献；甜区 = 最近 6–18 个月才变得可行；同时看竞争面（多人同时看到同一甜区时，速度或独门角度才是要件） |

范式探针（分渐进题与换范式题用，不是门；纯渐进照样可结题）：四问——点名并被推翻了一条公认第一性假设？处理了社区看见、多年绕开的大象？依赖两年前还不存在的能力？若成立会不会改社区的优先问题清单？各问答 Yes=2 / Partial=1 / No=0：0–2 纯渐进、3–4 有破坏性种子、5–6 破坏性潜力、7–8 换范式候选。探针分不改变放行结论，只决定「题面与结论段的口气是否与实情相称」。风险三分类随分档记录：执行风险、接受风险、时程风险；一仓派题的配比按多数渐进、少数激进排。

派题单落 `research_project/立项规划.md` 大课题节，字段：一句话故事（说不出一句话 = 题未成形，别急着评）·题源行锚（结题 open questions 原行或本文件某 gate）·强在哪一维·缺哪一维·成窗时间·可行三查结果·致命伤预筛（≤2 条）·探针分档·门类（新问题的提出 / 新方法 / 新设定，三选一钉死，全篇按它论证）。

## ② 十透镜 + 八引擎（生成器；speculator 生成段、pi 起手）

| 透镜 | 动作 | 自检（未过即弃） |
|---|---|---|
| 1 问题先行 / 方案先行 | 一句话写 idea，判定属哪类；方案先行必须点名 ≥2 个真问题 | 说得出具体谁在受苦；解的是没被解、还是只没被卖 |
| 2 抽象梯 | 同一焦点各出一个上移（一般原理）/ 下移（最受限实例、极端）/ 平移（同层别域）变体 | 每格单独问「够不够一条最终验证依据」 |
| 3 张力猎取 | 列本领域 3–5 条都想要的性质 → 找被当成 trade-off 的配对 → 问取舍是根本的还是当前方法的产物 | 能否各举一篇只优化一侧的独立工作（举不出 = 臆造张力）；可调和则调和本身即贡献，不可调和则刻画前沿亦有价值 |
| 4 跨域移植 | 先用剥掉领域名词的关系/因果语言重述问题，再找最远的结构匹配 | source 域专家会认可机制被正确理解吗；这条类比给出什么事先不知道的预测 |
| 5 What Changed | 挑 3–10 年前的负结果或被放弃的方案 → 列出导致否决的假设 → 逐条问今天是否还成立 | 句式必须填得满：「X 以前不可行因为 Y，如今 Z 已变」 |
| 6 失败边界探针 | 选一个报告结果很好的流行方法 → 列出它评测里的隐含假设 → 逐条违反（OOD / 尺度 ×10 与 ×0.1 / 对抗 / 组合 / 时间漂移）→ 记何处崩 → 诊断根因 | 能解释为什么失败，不只是知道它失败；收口要么给修法要么论证失败是本质的 |
| 7 简洁性检验 | 把 SOTA 剥到唯一关键想法，同算力同调参公平重建 | 警告四条：超参最优区间极窄、消融显示多数组件只有边际贡献、简单基线从未被认真调过、提升落在噪声内；差距小 → 简洁即贡献，差距大 → 写清复杂性买的是什么 |
| 8 干系人轮换 | 同一系统分别按端用户 / 维护者 / 被评测对象 / 竞争方法作者 / 关口审稿五种视角各列一条摩擦 | 五种视角说出同一个问题 = 视角没换 |
| 9 组合 / 分解 | 两个互补子问题的方法配对；或把纠缠的单体制拆成可单独摘除的模块 | 组合须说清接口在哪个假设上成立；分解须每模块可单独消融 |
| 10 两句话测试 | 句 1 问题「<领域> 目前在 <具体问题> 上受挫，因为 <具体后果>」；句 2 洞见「我们 <做法>，靠 <关键机制>，之所以成立是因为 <原因>」 | 填不出来按缺的那半句退回对应透镜 |

八引擎（认知操作，与十透镜叠用）：

- ① 双域交叉积：两域各列 5–10 个原语做笛卡尔积，逐格问「A 的概念用于 B 的问题意味着什么」；机制可迁移才算，表面比喻不算。② 问题重述六策略：换目标 / 换形式化 / 换粒度 / 换主体 / 换时标 / 换方向。
- ③ 类比分级：surface / relational / structural 三级，只有结构级映射进假设段；生不出新预测的类比是装饰。④ 约束操作见下节「约束分型」。⑤ 否定与反转：把公认假设逐条取反，看什么系统出现（「必须有标签」→ 自监督，「推理必须一遍完成」→ 迭代细化），配 TRIZ 六原理到 CS（反转 / 分段 / 合并 / 通用化 / 嵌套 / 动态化）。
- ⑥ 抽象梯升降。⑦ 相邻可能见 ① 时机 gate。⑧ Janusian 双面：同时握住两个矛盾主张不求选边，造出超越对立项的新框架。
- 四拍协议：制图（约束三分 + 近期成窗能力）→ 造扰动（否定 3 条 soft/hidden + 交叉积 + 重述三次）→ 加深（结构类比出预测 + 上下抽象 + 求合题）→ 评价（两句话测试）。
- 节拍铁律：生成在前、评价在后，生成段禁止自评，评价交 examiner / qa。解阻塞对照：固着 → 强制换表征；隧道视野 → 引入远域类比；自我审查 → 先造后评；渐进主义（每条都是「+2%」）→ 改规则不改参数；分析瘫痪 → 只看当下哪条可行；假两难 → 求合题。
- 收敛五道 kill 闸：两句话说不清 = 还没想清楚；没人为此受苦 = 丢；更简单的办法够用 = 简化或丢；无明确受益者 = 丢；明显不可执行 = park。胜出者必须落成三件：3 个可验证实验、预判最强反对意见并备好回应、一个两周内能出信号的试点。

## ③ 约束分型（hard / soft / hidden）

列当前范式约束 5–10 条（计算 / 方法 / 架构 / 评测四类各至少一条），逐条打标：

| 类 | 判据 | 操作 |
|---|---|---|
| hard | 物理或逻辑必需，违反即不自洽 | 不许动；动它等于换赛道，须重开题 |
| soft | 惯例与历史偶然 | 可问放松 / 收紧 / 整体替换三种后果 |
| hidden | 未言明、被默认 | 最肥的创新来自暴露并丢弃一条 hidden 约束：点名 → 丢弃 → 说明丢弃后什么变得可能 |

pi 头四段「问题背景」应带这张表的一部分；examiner 据此生成一类固定弹药：「你把一条 soft 约束当 hard 用了」。

## ④ 动笔前五问（倒序想，正序写）

1. 解的是什么技术问题？**为什么没有成熟解法**（必答闸，防把已有做法当创新；答不出 = 要么已被做过，要么这不是技术问题）
2. 我们的贡献是什么（新任务 / 新指标 / 新问题 / 新技术，择主导一条）
3. 本质上为什么可行（要机制链条，不接受「实验显示」）
4. 技术优势与新洞察是什么（优势须挂到可测行为上）
5. 借哪些前人方法把读者引到我们所解的那个挑战上

任一问答不出：pi 不出手头四段，speculator 不落假设段。五问的答案随即落成「贡献四段」一张小表（落笔先于散文，头四段定稿前跑一遍）：

- 核心主张：一句话、可证伪，门类三选一，再配一句「读者从这一条里拿到什么」。为何需要：领域问题 + 精确缺口（禁「X 少有人研究」式含糊，缺口不可测等于自认不可测）+ 是什么让这个缺口至今合不上 + 最近的前作各为何没解掉它。
- 本文如何回应：机制响应 + `Evidence required`（先列怀疑者会要什么证据，再看自己有什么）+ `Evidence available` + `Evidence missing`。missing 非空只有两种合法动作：软化主张，或去补实验；禁止原样写进结论段。
- 主张边界：允许全力说的主张 / 须软化或删掉的 / 新颖性风险一行（最可能的「这已被 X 做过」与诚实回答）/ 重要性风险一行（最可能的「so what」与诚实回答）。
- 动机反推：手上已有 `measured/` 现象时，先据读数列 3–5 个候选问题（同一批数可被多个问题解释），选定一条主线；主线必须落在读者可见的表面（题目、摘要顺序、目的句、直接证据节）。论证链与落笔段的映射归 `paper-writing`，本文件只管前五问与这四格。

## ⑤ 致命伤十条 + 短路 + 反向保险

门槛三条（偏保守，不是所有弱点都算致命伤）：在题面/头四段里就看得见、不是做实验才发现；换强基线或改措辞都救不了；首轮就会被人点。

| # | 致命伤 | 开火问句 | 化解动作 |
|---|---|---|---|
| F1 | 无新颖性 | 相对唯一最近的前作，本项多出的那一句是什么？ | 说不出、或答案是「用了更大的模型」「把两个已有方法拼起来」= 实锤；差异须落在作用对象 / 机制 / 输入粒度 / 问题设定四轴之一，光标题相似永远不构成重复 |
| F2 | 门类错配 | 一句话故事属于哪一类（新问题 / 新方法 / 新设定）？ | 定不下来 = 全篇论证方向互相拉扯；钉死一类再写 |
| F3 | 基线不是真基线 | 目标 benchmark 最近三个月最强公开结果是谁、多少？ | 基线比它旧 12 个月以上或不引近期结果 = 无效基线，按评测契约重立 |
| F4 | 无说服性动机 | 明天解决，谁受益、多少？ | 只答「同方向研究者」= 红旗；补外部受益者 |
| F5 | 能力不匹配 | 现有评测器、算力、数据与角色链能否跑完一轮完整链条？ | 两处以上不匹配即致命；可缩范围或先建工具 |
| F6 | 主张不可验证 | 什么实验出什么结果能证主 claim？ | 设计不出来、或该实验不在范围内 = 不可测实锤 |
| F7 | 准入阻塞 | 所需数据 / 权重 / 人类对象当前可及吗？ | 触禁区三条（外部付费数据集、私有权重）的题不派 |
| F8 | 范围过度膨胀 | 结论段声称几条贡献？ | >4 条或跨门类（数据集 + 方法 + 理论 + 系统）= 每条被其余拆台，砍到一条主线 |
| F9 | 拿着技术找问题 | 是先在实践中撞见问题，还是先挑了技术再找地方用？ | 说不出一个具体现实失效例 = 前提崩塌 |
| F10 | 未考虑失败情形 | 说不出两条失效模式与对应条件？ | 必然越依据；预登记两条失效模式再开工 |

硬规矩：

- 一条题最多列两条致命伤，超过两条说明方向本身错了 —— examiner 直接 fail 归案、planner 换题，别救。
- 严重度：一周内文字/文献可补 = MINOR；需 2–4 周实做 = MAJOR；资源条件下救不到生命周期内、或 MAJOR ≥2 = CRITICAL。
- 短路：任一 CRITICAL → 判词直接落 Reject / fail，不写第三条到第六条小节，不填中间表格（省下的篇幅用来把那一条 CRITICAL 的锚写全）。

反向保险（防过早归案，两条对称）：

- 数据反证 ≠ 机制未测。作者自己报的 `measured/` 数据里核心机制已被基线、消融或简单对照追平/超过 → 自动 CRITICAL 且锁死判词：被反证的指标禁止当主打故事、不写 defense、不许造一个刚好能过的阈值、更不许写成「再跑几小时就成立」（建成的机制输掉是前提被证伪，不是努力缺口）。机制只是未测时，禁止用这条杀好点子：走机制型高分 + 点名验证实验。
- 零读数不折算低分。机制扎实、尚未实测的题可以拿高分，条件是打机制标签并点名验证实验；不得把这类题系统性封顶。红线只有一条：没有实验就一个字数字都不许出现。

### 固定问句：结构性缺陷（分析阶段救不回来，选题期就得判）

八条设计红线（本飞轮口径）：重复测量当独立重复（一个模型的 100 个 batch ≠ n=100）；条件与 nuisance 变量同轴（周一跑臂 A 周二跑臂 B）；随机化缺失或走样（按先来后到分配配置）；无同期对照臂；批次/环境漂移被当成效应（依赖版本、checkpoint、机器与条件对齐）；位置/顺序效应（永远只取前 k 条、只用固定 shard）；多配置共用一份 held-out 造成混叠，不看别名结构就断言「该因子无影响」；只有两个取值就谈最优（无曲率证据）。

七类反复失败：分析单元错（把行 / patch / 窗口 / 帧当独立受试者，虚增 n 造出显著）；乐观切分（同源系列、模板重复、时间与空间自相关之上做随机切分）；成分数据当绝对量（归一化占比里一个涨必使其余跌）；阈值他领域照搬（沿用别人 benchmark 的通过线，不测自己的噪声底）；静默坐标系不一致（tokenizer、模型 revision、评测 harness 配置、单位与分母——join 成功而答案错）；预测当测量（proxy 分数、归因值当成机制本身）；double dipping（用评测集挑 checkpoint 或调阈值、同一批数据定义子集再在该子集上报增益）。

用法：这十五问是 examiner 的固定开火表，也逐条写进 pi「自证断言」旁边当自查。命中且无法在题面内化解 = MAJOR；命中「独立重复错 / 乐观切分 / double dipping」任一 = CRITICAL（结构性，只能改设计，不能改分析）。逐条的机器可核版归 `experiment-design` 与 qa 三约束。

## ⑥ 四条自洽检查（= 「自相矛盾」攻击的可操作定义）

链条：问题背景 → 目的与最终验证依据 → 挑战 → 设计段模块 → 结论段贡献。四查各跑一次双向覆盖，任一断 = CRITICAL，必须在动笔前修：

- Check1 每条「现有方法何处失效」是否被头四段的「目的」与「最终验证依据」直接或间接回应。反例：抱怨「不能 scale 到大 schema」，Key Idea 只提「用 CoT 做 schema linking」——只涨准确率不涨规模，断。
- Check2 每条挑战是否由实现「目的」段那句机制自然产生。反例：机制是 inference-time MCTS 搜索，挑战写「标注数据贵」——MCTS 免标注，属发明出来的挑战，删。
- Check3 模块 ↔ 挑战一对一双向：孤儿模块 = 在解决没人提的问题；孤儿挑战 = 没有模块来接。
- Check4 模块 ↔ 贡献双向：贡献声称「收敛性理论分析」而 `lean/` 里没有一份对应推导 = 越权声称。

另两条常断法：Key Idea 漂移（设计段填完回读「目的」段，措辞与实际发展的机制已分叉）；Limitation–贡献短路（某条贡献不回应任何失效，全文解的不是它自己提出的问题）。三件不相交小事打包成「一个框架」也记断链。theorist 的推导链管前提—结论可编译，本检查管叙事承重墙对齐，两者互补，各出一份通过记录。

## ⑦ 五维打分纪律（planner 定档 / qa 归因）

五维 = 更准（效果）· 更快（效率）· 更稳（鲁棒与泛化）· 更省（数据与解法成本）· 更广（跨域与统一），每维 1–10。

- 从 5 起，只允许两类 grounds 动分：其一，作者报出的**实测**数字（不是计划值、不是预算承诺），必须引用原句或 `measured/` 路径；其二，站得住的机制论证，必须打 "mechanism-based, not yet confirmed by data" 标签并点名一条验证实验（该实验同时写进 top-three actions）。两者皆无 = 停在 5，注明 "no grounds given"。
- 归因封顶：亮眼涨幅可能来自外围因素（路由、后处理、更强底座模型、有利样本、更弱基线）。拿到隔离消融之前，封顶该维。检验句统一：把外围那步拿掉，核心机制还剩多少涨幅？剩得不多 = 归因没挣到。这就是 qa 断言对表里的归因条款，两处同一措辞。
- 定档：最高维 ≥8 且次维 ≥6 → 值得主打，写进派题单「强在哪一维」；≥3 维 ≤5 → 题薄，要么找到真强的那一维要么换；五维全 ≤4 → 不派；无一维 ≥7 → 说法含糊，退回要求点名唯一主轴。五维分只用于派题定档与中期归因讨论，不作结题分数：合议是非补偿判断，归 `review-discipline`。
- 五种打分失效：通胀（每维 7、8 显得慷慨）、通缩（每维 3、4 = 没读懂，重读）、分数无引证（指不回题面一句话的分数不算分数）、提分建议泛泛（「换个 prompt 试试」不算，必须点名一个入口策略）、分数与定档不符（无一维过 7 却写进「强在哪一维」）。

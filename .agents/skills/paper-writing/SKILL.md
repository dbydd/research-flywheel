# 论文写作

本规范覆盖四部分：稿件骨架、LaTeX 排版规则、措辞纪律、修订流程。

## 来源

外部细则来自 https://github.com/guanyingc/latex_paper_writing_tips 的 `paper_writing_tips.pdf`（Guanying Chen，CVPR/ECCV 实战总结）。流程约定来自本飞轮。修改本文件时，保留出处。

## 稿件骨架

每一节回答一个问题。按下列骨架组织稿件。

- Abstract。顺序：问题 → 方法一句话 → 最强结果带数字 → 意义。写四到六句。Abstract 零引用。缩写先定义后使用。
- Introduction。顺序：领域地位 → 缺口 → 我们做了什么 → 贡献列表 → 路线图段（可选）。缺口写现有方法哪里不行，引文献撑住。贡献列表三条上下，每条可验证。
- Related Work。按技术线索分组叙述。每组末尾收一句「与本文的关系」。按时间罗列流水账是拒稿常见理由。
- Method。符号先定义后使用。一张总览图配数据流叙述。每个小节对应一个组件。
- Experiments。顺序：setup → 主结果 → 消融。setup 覆盖数据、指标、实现细节、硬件。每张表、每张图在正文里有指涉句与结论句。数字与 `measured/` 一致。
- Conclusion。局限写诚实。future work 一句一个。

## LaTeX 排版规则

以下规则逐条对应 PDF §2。

### 标点与空格

- 左括号前留空格：`network (CNN)`。左括号贴前文算错。
- 句号、逗号前零空格。
- 引用前留空格：`problem [1]`。
- 公式是句子的一部分，公式末尾放标点。全部公式编号，交叉引用才有着落。
- 双引号用 `` `` `` 和 `''`。直引号 `"` 排版出来是错字。
- 句首大写。

### 引用与指涉

- Abstract 零引用。
- 表格指涉写全 `Table 1`。句子里写 `Tab. 1` 算错。
- 图指涉分位置：句首写 `Figure 1`，句中写 `Fig. 1`。`Fig.1` 缺空格算错。
- 表题在表上方，图题在图下方。浮动体尽量放页面顶部。
- 高频词定义宏：`\newcommand{\NetName}{...}`。改名时改一处，全文生效。
- `i.e.`/`e.g.` 用 `\ie`/`\eg` 宏。宏防止句读错断与换行断坏。

## 措辞纪律

措辞规则约束主张强度与数据对应关系。

- 主张强度对齐证据。消融只涨 0.1 时，删掉 `significantly outperforms`。`state-of-the-art` 需要对照表支撑。
- 全篇时态一致。描述已有工作：现在时或过去时二选一。描述本文实验结果：过去时或现在时择一。
- 每个数字都能指回 `measured/` 一个文件。指不回去的数字删除。
- 图表未引用的先删除。要保留的图表先补指涉句。

## 流程约定（本飞轮）

- 成稿放 `papers/<run-id>/`：main.tex、refs.bib、figs/，编译出 main.pdf。LaTeX 工程放 role ws 私有区。定稿一次性发布。
- 每轮修订在稿件头部留一行修订记录。记录三件事：日期、改了什么、响应 critic 哪条。
- critic 打回的文字问题逐条改。每条在修订记录里销账。

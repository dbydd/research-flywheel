# librarian

## 岗位自检（handoff master 之前过一遍）

增强页四条，条条落在页面上：

1. 五问逐条有答：这份资源做了什么、立在什么之上、相关引用落在哪里、哪个组或谁做的、作者有什么特点；查不出的明写「未查明」，不凑数。
2. 每条结论带来源：URL 加访问日期；博客视角标明作者身份——内部视角与中立事实是两种货，混装要标明。
3. 落点对树：论文 `papers/context/`、文章 `blogs/context/`；一页一资源，slug 唯一，frontmatter 七键齐。
4. 只画脉络，不写精读判断——判断是 master 的活，我先写了它就没得写。

本节是模板给的岗位自检，我不改写它：手记只动「记叙」「条目」两段。

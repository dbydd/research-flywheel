# scriber

记叙与条目写在本 ws 的 `STATE.md`。

## 岗位自检（handoff librarian 之前过一遍，缺一件不出手）

入库完整性四条，条条对着磁盘查，不凭印象：

1. 一资源一目录：快照与抽取双件齐——论文是原件 PDF 加 `<slug>.extracted.md`，网页是快照 HTML 加抽取正文；正文抽不出来就写明原因，不留空件。
2. 图进 `assets/`，命名 `<slug>-fig<N>`；摘要页引用走相对仓根路径。
3. 摘要页七键齐（`title`/`slug`/`type`/`created`/`updated`/`sources`/`resource`），type 与所在目录一致，slug 全库唯一，树别放错（论文 `papers/`、文章 `blogs/`）。
4. 日期与出处取页面真实值，取不到就标明，不猜。

残差流一条不落：本跳产物逐行列全，下游全靠它开工。

本节是模板给的岗位自检，我不改写它：手记只动「记叙」「条目」两段。

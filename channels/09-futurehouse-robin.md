# 09 - FutureHouse Robin：端到端自主发现平台

| 字段 | 内容 |
|------|------|
| **机构** | FutureHouse（旧金山非营利 AI for Science 研究所，Eric Schmidt 资助）；创始人 Samuel Rodriques 等；2025-2026 期间发布 Robin、ether0、PaperQA2 |
| **论文/发布时间** | 2026-05 Nature 首篇端到端 AI 自主发现论文：以干性年龄相关性黄斑变性（dAMD）为靶点发现 ripasudil；2025 年中发布 ether0（24B 化学推理模型）与平台综述；futurehouse.org 公告与 IntuitionLabs 平台指南 |
| **用途** | 自动化科学发现全流程：文献挖掘、假设生成、实验设计、数据分析、机制阐释；首个验证案例为 dAMD 新疗法发现，展示从假设到体外验证的闭环无需人类实验设计干预 |
| **验证状态** | 已完成体外湿实验验证：RPE 吞噬功能提升约 1.9 倍、ABCA1 上调 3 倍；全流程约 10 周完成，宣称研究者时间节省约 200 倍；后续临床前验证由合作方推进 |

## 循环形态

Robin 采用多智能体编排的端到端循环，核心为 Robin 统筹，子智能体各司其职：

1. **文献与假设**：Crow 回答文献问答，Falcon 做深度综述，Owl 检测已有工作避免重复，Robin 在此基础上提出 dAMD 中增强 RPE 吞噬作为治疗策略的新假设。
2. **候选筛选**：Robin 检索 FDA 已批准分子库，筛选可重定位到 dAMD 的候选，提出 ripasudil 等 Rho 激酶抑制剂。
3. **实验设计**：Robin 自动设计体外实验：RPE 吞噬荧光测定、剂量梯度、对照设置，产出可执行实验方案。
4. **执行与分析**：实验由合作湿实验室执行，Robin 的 Finch 智能体分析返回数据，提出 RNA-seq 机制实验，发现 ABCA1 脂质外排泵上调为潜在机制。
5. **迭代深化**：基于机制发现，Robin 提出第二轮验证实验，闭环持续至假设得到多维证据支撑。

循环特点是文献到实验设计的无缝衔接，Robin 在每一步保留决策 trace，支持审计与回放。平台愿景延伸至与人形机器人结合实现物理执行闭环，当前物理执行仍依赖人类实验室。

## 智能体架构

| 角色 | 职责 | 基座/说明 |
|------|------|-----------|
| Crow | 文献问答与快速检索 | 专用问答 Agent，基于 PaperQA2 |
| Falcon | 深度文献综合与综述 | 长文综合 Agent |
| Owl | 已有工作检测与新颖性判断 | 去重与新颖性 Agent |
| Phoenix | 化学合成设计 | 分子设计 Agent |
| Finch | 复杂数据分析 | 数据分析 Agent |
| Robin | 统一编排与端到端决策 | 集成以上能力的多智能体系统，基座为 o4-mini / Claude 3.7 等未微调通用模型 |
| ether0 | 化学推理专用模型（24B） | Mistral 24B Instruct 微调 + RL，输出 SMILES，支撑 Phoenix |

Robin 未对基座做任务特化微调，依赖 prompt 编排与工具链，验证了通用模型通过架构即可实现自主发现。

## 工具/数据库

- **PaperQA2**：开源文献问答与综合工具，支撑 Crow/Falcon/Owl。
- **ether0**：24B 化学推理模型，Apache 2.0 开放权重，含 benchmark 与 reward model，Hugging Face 可用。
- **FDA 已批准药物库**：用于重定位筛选。
- **RPE 吞噬测定与 RNA-seq 分析管线**：实验设计模板与数据分析脚本由 Finch 调用。
- **平台基础设施**：FutureHouse 云端编排、实验方案生成器、数据分析沙盒；2025 年分拆 Edison Scientific（估值 2.5 亿美元）推进商业化。
- **文献与数据库**：开放获取文献、通路与疾病数据库隐式调用。

## 度量

- **生物学指标**：RPE 吞噬荧光强度提升 1.9 倍、ABCA1 表达上调 3 倍、剂量响应与对照显著性。
- **系统指标**：假设到验证总时长约 10 周（2.5 月）、研究者时间节省约 200 倍、假设新颖性（与既有文献重叠度）、实验设计可执行率。
- **模型侧**：ether0 在化学任务上超越通用 LLM 与人类专家（见 FutureHouse 基准）。
- **平台侧**：多智能体协作成功率、文献综合准确率、数据分析可重复性。

## 闭环验证（湿实验/临床）

湿实验在合作实验室完成：RPE 细胞系吞噬实验、Y-27632 等对照、RNA-seq 机制验证。Robin 未直接操作物理设备，但产出的实验方案与分析脚本被湿实验室原样执行并返回数据，形成数字到物理的闭环。该案例被宣传为首个 AI 端到端自主发现药物候选，临床验证仍待后续动物与人体研究。

## 开源状态

部分开源。PaperQA2 与 ether0（权重、benchmark、reward model）以 Apache 2.0 开放；Robin 平台本身为 FutureHouse 非营利托管的开放访问服务，非完全开源部署。Edison Scientific 负责商业化延伸。

## 核心可借鉴点

1. **角色分解到工具级**：每个子智能体对应一类工具（问答、综述、合成、分析），职责清晰，易于独立升级。
2. **通用基座 + 架构取胜**：无需为 dAMD 特化微调，证明架构与工具链比模型微调更关键。
3. **假设-实验-机制三段闭环**：不仅做筛选，还自动提出机制实验（RNA-seq），提升发现可解释性。
4. **重定位优先**：从 FDA 已批准库出发，显著降低验证门槛与成本。
5. **开放权重锚点**：ether0 作为化学推理锚点，可复用到其他生物医学渠道。

## 潜在坑

- 物理执行仍依赖人类实验室，闭环频率与质量受合作方响应速度限制。
- 通用基座未微调，对长尾生物医学细节易出现幻觉，需强检索 grounding。
- 单一成功案例（dAMD）被过度宣传，泛化到其他疾病的能力尚未充分验证。
- 200 倍效率提升的计算口径不透明，需谨慎引用。
- 多智能体编排复杂度高，调试与溯源成本大，失败时难以定位责任 Agent。

## 落到 OMP Workspace 的可实现机制

| 借鉴点 | OMP 实现 |
|--------|----------|
| 角色分工具 | `template/robin-agents/` 下为 Crow/Falcon/Owl/Phoenix/Finch 各建独立 prompt 与 tool 白名单，Robin 为 supervisor 通过 `hub` 分发 |
| 重定位优先 | 在 `template/tool-registry.json` 首批注册 FDA 已批准药物工具，`channels/09-*` 默认先筛该库再扩展 |
| 机制实验自动提出 | Finch 分析后必须产出 `mechanism-hypothesis.md`，触发第二轮实验设计，未产出则阻塞 |
| 开放锚点 | ether0 权重接入 `tools/ether0/` 作为 SMILES 推理服务，供其他生物医学 channel 复用 |
| 端到端 trace | 每轮假设、实验方案、数据、分析写入 `local://robin/trace-{date}.md`，支持回放与审计 |

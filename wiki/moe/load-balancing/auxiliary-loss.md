# Aux Loss 与 F·P 的来路

Aux Loss（辅助损失）是加在语言模型损失之外的损失项，作用是推动负载均衡。它与语言模型损失一起被优化，本身不承担预测下一个 token 的任务。负载分布与两类浪费的记号见[[load-balancing-problem|负载不均衡的两类浪费]]。

## 通行形式

文献里的辅助损失写作 `F·P`，这里的「·」是内积，把两个同长向量的对应分量相乘再求和，得到的是一个标量。`F` 是 Top-k 指示向量在全体 token 上的平均，也就是当前负载分布；`P` 是归一化打分在全体 token 上的平均。部分文献会在此基础上再乘一个 n，让损失的尺度与专家数挂钩。

## 来路

第二篇补上了这条损失的推导。作者见到的文献与科普多半直接用 `F·P`，不作证明。

推导从「让 `F` 逼近均匀分布」出发，按下面几步走完。

1. 目标：让当前负载分布 `F` 靠近均匀分布。
2. 度量：写出一个衡量 `F` 与均匀分布距离的损失。
3. 障碍：`F` 由 Top-k 指示向量取平均得到，而从 n 个分量里挑出前 k 个是离散的选择动作，梯度无法穿过这一步，`F` 在计算图上不可导。计算图指框架记录的张量运算关系，自动求导沿它从损失往回累积梯度。
4. 手段：用直通估计替换这个不可导项，反向改用可导的 `P`，见[[straight-through-estimator|直通估计与 F 换 P 的配方]]。
5. 结果：对这个损失求梯度，得到的形式恰好落在 `F·P` 上。通行形式由此有了来路，它是那个距离损失在直通估计下的梯度。

## 读数条件

`F·P` 承载的是等效梯度的意义：把它代进自动求导，得到的梯度与那个可导的距离损失相同。由此，`F·P` 的数值下降与均衡程度改善是两件事，前者的读数应当换算回梯度再看。

## 局限

权重系数难调：调低起不到均衡作用，调高损害语言模型损失。

直通估计给出的梯度是次优的：反向用的替代梯度与真实梯度的方向存在差距，辅助损失据此拿到的均衡压力带有偏差。

恒定权重在分布畸形的层上很难实现均衡，模型前几层用 MoE 时不均衡尤其常见。这些是第三篇转向 Loss-Free 的直接动因，见[[loss-free-balancing|Loss-Free 负载均衡：偏置与符号更新]]。

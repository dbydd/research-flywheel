# 批量与学习率的缩放律重拟合

新架构与新优化器改变了最优批量与学习率的位置，沿用旧配方会落在次优区间。Qwen3.8-Flash-Next 重拟合缩放律，把最优点向更大批量与更高学习率推，再用两处检验验它。

## 推导链

链条六步走完：新架构与新优化器在[[training-stability-stress-test|压力测试]]里明显更稳；稳定性余量意味着更激进的超参可用；重拟合 Kaplan 一路的批量与学习率律；预测点向更大批量与更高学习率移动、学习率随模型变大的衰减变慢；两条预测各自放到最敏感的区间检验；兑现。

## 批量检验

放小模型长训，20 层 10.8B-A0.89B、4T token，各 run 同 token 预算，读数取末段最后 20B token 的损失均值：

|批量|学习率|末段损失|
|---|---|---|
|12.6M（旧配方）|$3.49\times10^{-3}$|1.5774|
|25.2M（预测最优）|$5.39\times10^{-3}$|1.5702|
|37.7M（再放大 1.5 倍）|$6.92\times10^{-3}$|1.5707|

预测点比旧配方好 $7.2\times10^{-3}$，再放大 1.5 倍只亏 $4.3\times10^{-4}$。损失在预测点下方陡升、上方近平，预测点贴着最优盆的左壁，盆向右宽。

> **批量扫描图**（技术报告 Figure 8）(a) 三个常数批量档的损失随消耗 token，插图放大末 50B token；(b) 两条 ramp 对常数基线。

## 批量 warmup 判废

两条 ramp 分四段、每段加 6.3M，从 6.3M 抬到 25.2M，524B token 处到顶；一条保持常数批量最优的峰值学习率，一条下调峰值学习率配早期小批量。两条都落在 run-to-run 方差内，分别比常数基线差 $2.5\times10^{-4}$ 与 $3.5\times10^{-4}$，还多花 18.8% 优化步。

机制叙述完整：爬升期同学习率下小批量梯度噪声更高、损失更高；批量到位后短暂领先来自早期攒下的更多优化步；学习率衰减、接近收敛时步数优势被中和，常数批量最终胜出。稳定性无碍：没有哪一步的损失超出局部中位数 0.1 以上，p99.9 未裁剪梯度范数 0.088–0.190，裁剪阈值 0.5。这条判词把批量 warmup 收进[[three-axis-architecture-eval-protocol|三轴评估协议]]拦下的三条捷径清单。

## 学习率检验

放大模型、缩预算，48 层 156B-A7B、419B token。预测最优 $(B=8.4\text{M},\ \eta=1.76\times10^{-3})$，旧配方 $(4.2\text{M},\ 6.8\times10^{-4})$ 高 $7.8\times10^{-3}$；四个邻近设置（预测最优点 $8.4\text{M}$ 配 $1.76\times10^{-3}$、学习率除 $\sqrt2$ 的 $1.24\times10^{-3}$、学习率乘 $\sqrt2$ 的 $2.49\times10^{-3}$、批量加 25% 配匹配学习率的 $10.5\text{M}$ 配 $2.01\times10^{-3}$）彼此差在 $7\times10^{-4}$ 内、贴近噪声，$B\times1.25$ 名义最好、领先 $3\times10^{-4}$。最优点坐在至少 $\pm2$ 倍学习率与 $+25\%$ 批量宽的平盆底部。

下游七项均值 60.55 对旧配方 56.41，报告自己给排序加限定：单次评估、排名前四的设置差距小、差异大概落在评估噪声里，读数按观察量处理。稳定性同步兑现：五个 run 在 warmup 之后裁剪器一次未触发，预测最优点最大未裁剪梯度范数只到阈值的 28%，旧配方 51%（小批量梯度更噪）。

## 不可复算的部分

报告只给出预测值与检验值，重拟合后的函数形式、拟合数据点、指数一个都没写。两处预测各自的检验是干净的（批量放 4T token 长训、学习率放 419B token 大模型短训，各在最敏感区间验证），从拟合到预测的推导链在报告正文里断了。生产件 125B-A6B 的实际批量、学习率与总 token 量报告也未写，缩放律检验用的是 10.8B-A0.89B 与 156B-A7B 两档代理。
